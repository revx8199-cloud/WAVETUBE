# 🌊 WaveTube

**WaveTube — это как YouTube, но лучше.**

Полноценная видео-платформа, реализованная как одностраничное веб-приложение: загрузка и просмотр видео, социальная лента с постами и опросами, каналы, подписки, живые уведомления, VIP-плюшки и полноценная админ-панель. Сделано полностью через промпты (вайб-кодинг), без единой строчки кода вручную.

🔗 **Живой сайт:** https://revx8199-cloud.github.io/WAVETUBE/

---

## ✨ Фичи

### Основа платформы
- Свой видеоплеер (прогресс-бар, индикатор буферизации, громкость, полный экран)
- Каналы с аватарками, подписками и уведомлениями подписчикам
- Соцлента: текстовые/фото-посты, опросы с живым подсчётом голосов, комментарии, лайки
- Живые обновления (новые посты, уведомления) через Supabase Realtime
- Система присутствия (кто сейчас онлайн)
- Списки "Сохранённые видео" / "Посмотреть позже"
- Светлая и тёмная тема, сохраняется в localStorage
- Мультиязычный интерфейс (польский, русский)

### VIP и админ-системы
- **VIP-панель** — плюшки для VIP-пользователей (кастомные цвета/шрифты ника, значки)
- **Админ-панель** — управление пользователями, мут/бан, настройка цвета бейджей
- **Админ-консоль** — инструменты модерации и контроль над платформой
- Система жалоб на контент
- Панель статистики активности платформы

### Безопасность
- Защита от XSS в пользовательском контенте (посты, комментарии, поля профиля)
- Политики Row-Level Security настроены в Supabase
- Ограничение частоты публикации постов (rate limiting)

## 🛠️ Технологии

- **Фронтенд:** чистый HTML/CSS/JavaScript (всё в одном файле)
- **Бэкенд:** [Supabase](https://supabase.com) — авторизация, база данных Postgres, Realtime-подписки, Row-Level Security
- **Хостинг:** GitHub Pages
- **Шрифты:** Google Fonts (30+ декоративных шрифтов для кастомизации ника)

## 🚀 О проекте

WaveTube — сольный пет-проект, полностью созданный через промпт-разработку с Claude — ни строчки кода вручную, только итерации через естественный язык и тестирование. Начиналось как простая страница с видео, а выросло в полноценную соцплатформу со своей модерацией и VIP-инфраструктурой.
