# 🌊 WaveTube

**WaveTube — это как YouTube, но лучше.**

Полноценная видео-платформа: загрузка и просмотр видео, Shorts (вертикальная полноэкранная лента), социальная лента с постами и опросами, каналы, подписки, личные сообщения со звонками/видеозвонками, живые уведомления, VIP-плюшки и полноценная админ-панель. Сделано полностью через промпты (вайб-кодинг), без единой строчки кода вручную.

🔗 **Живой сайт:** https://revx8199-cloud.github.io/WAVETUBE/

---

## ✨ Фичи

### Основа платформы
- Свой видеоплеер (прогресс-бар, индикатор буферизации, громкость, полный экран)
- **Shorts** — вертикальная полноэкранная лента в стиле TikTok/YouTube, с автовоспроизведением, лайками/дизлайками, комментариями и шарингом
- Каналы с аватарками, подписками и уведомлениями подписчикам
- Соцлента: текстовые/фото-посты, опросы с живым подсчётом голосов, комментарии, лайки/дизлайки
- Личные сообщения со звонками (push-уведомления браузера при закрытом приложении, через service worker)
- Живые обновления (новые посты, уведомления) через Supabase Realtime
- Система присутствия (кто сейчас онлайн)
- Списки "Сохранённые видео" / "Посмотреть позже", плейлисты
- Светлая и тёмная тема, сохраняется в localStorage
- Мультиязычный интерфейс: польский, английский, русский, испанский

### VIP и админ-системы
- **VIP-панель** — плюшки для VIP-пользователей (кастомные цвета/шрифты ника, рамки аватара, стили эмодзи, значки)
- **Админ-панель / Studio** — управление пользователями, мут/бан, настройка цвета бейджей, глобальные объявления
- Система жалоб на контент (видео, посты)
- Панель статистики активности платформы

### Безопасность
- Защита от XSS в пользовательском контенте (посты, комментарии, поля профиля)
- Политики Row-Level Security настроены в Supabase
- Ограничение частоты публикации постов, защита от накрутки лайков/дизлайков (серверная проверка по пользователю)

## 🛠️ Технологии

- **Фронтенд:** чистый HTML/CSS/JavaScript (логика разбита по нескольким файлам: core.js, videos.js, channel.js, posts.js, messages.js, admin.js, translations.js)
- **Бэкенд:** [Supabase](https://supabase.com) — авторизация, база данных Postgres, Realtime-подписки, Row-Level Security
- **Хостинг:** GitHub Pages
- **Шрифты:** Google Fonts (30+ декоративных шрифтов для кастомизации ника)


## 🚀 О проекте

WaveTube — сольный пет-проект, полностью созданный через промпт-разработку с Claude — ни строчки кода вручную, только итерации через естественный язык и тестирование. Начиналось как простая страница с видео, а выросло в полноценную соцплатформу со своей модерацией и VIP-инфраструктурой.
